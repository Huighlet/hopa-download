Installation Instructions

  1. Download the APK file using the button above.
  2. On your Android device, go to Settings > Security.
  3. Enable Install from Unknown Sources or allow browser installation permission.
  4. Open the downloaded APK from your notifications or Downloads folder.
  5. Follow the on-screen prompts to complete installation.
System Notice: Because this package is distributed directly outside Google Play, Android may present an unknown source confirmation prompt. The package is cryptographically signed and safe to install.

Key Capabilities

  • 100% Offline Capability: Operates without internet connectivity.
  • Secure Local Storage: All student records are stored encrypted on-device.
  • Comprehensive Student Profiles: Track grades, attendance, and continuous assessment.
  • Standardized Report Card Generation: Produces printable terminal academic transcripts.
  • Data Portability: Export and backup database snapshots locally.
