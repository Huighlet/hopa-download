# HOPA School Reports - Android Distribution

Landing and direct package distribution page for the **HOPA School Reports** Android application.

## Overview
HOPA School Reports is an offline-first mobile application designed for primary and junior high schools to manage student rosters, academic records, term grades, and terminal report card generation without requiring an active internet connection.
